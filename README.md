# NEXT3 Media — Website

React + Vite + Framer Motion single-page site.

- Edit business details (email, locations, social links, FAQ) in `src/data.js`
- Replace the logo at `public/logo.webp`

```bash
npm install
npm run dev
```

## Deploy (GitHub Pages)
Push to the `main` branch of a GitHub repo, then in **Settings → Pages → Source** choose **GitHub Actions**.
The workflow in `.github/workflows/deploy.yml` builds and publishes automatically.
